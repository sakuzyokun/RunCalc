# RunCalc

![Windows 7 / 8 / 10 / 11 Supported](https://img.shields.io/badge/OS-Windows_7%2F8%2F10%2F11-blue?logo=windows)
![Latest Release](https://img.shields.io/badge/Release-v1.0.0-green)
![License](https://img.shields.io/badge/License-Free-brightgreen)

Windowsの「名前を指定して実行 (Win+R)」から素早く使える、シンプルで高速な計算機アプリケーションです。軽量動作を追求しているため、古いPCでも快適に動作します。

---

## ⚡ 主な特徴

- **圧倒的な起動スピード**: 「名前を指定して実行」から一瞬で計算結果を出力
- **クリップボード自動コピー**: 計算完了時、結果が自動でクリップボードに保存（エラー時を除く）
- **連続計算モード**: UI上の `Calc...` を使用して続けて計算が可能
- **軽量動作**: 低スペック環境やレガシーなWindows環境でも快適

## 🚀 使用方法

1. `Win + R` キーを押して「名前を指定して実行」ダイアログを開きます。
2. `rc 計算式`（例: `rc 1+1`）と入力して `Enter` を押します。
3. 計算結果が表示され、同時にクリップボードへコピーされます。

> **Note**  
> 入力はすべて半角で行ってください。（掛け算は `*` 、割り算は `/` を使用）
