RunCalc is a simple, lightweight, and high-speed calculator application designed to work directly from the Windows "Run" dialog (`Win + R`). Optimized for fast performance, it runs smoothly even on older PCs.

---

## ⚡ Features

- **Instant Launcher Execution**: Perform quick calculations directly from the Windows Run dialog.
- **Automatic Clipboard Copy**: Results are automatically copied to your clipboard upon calculation (excluding errors).
- **Continuous Calculation**: Seamlessly chain subsequent calculations using the `Calc...` button.
- **Ultra-Lightweight**: Minimal system resource usage for smooth operation across various environments.

## 🚀 How to Use

1. Press `Win + R` to open the Windows "Run" dialog.
2. Type `rc [expression]` (e.g., `rc 1+1`) and press `Enter`.
3. The calculation result will be displayed and automatically copied to your clipboard.

> **Note**  
> Please use standard half-width characters for input (use `*` for multiplication and `/` for division).
